## 2. 今日做了什么

### 2.1 根因：Actions SSH ≠ 本机 SSH

| 现象 | 结论 |
|------|------|
| Actions 卡在「无法连接 :22」 | GitHub 国外 runner → 腾讯云轻量 **境外入站不可达** |
| 本机 `ssh -i tc_staging_deploy root@IP` | **通** |
| 服务器出网访问 github.com | **超时**（国内源 / baidu 通） |
| 防火墙已开 `0.0.0.0/0` 的 22 | **仍不够**：属机房国际带宽 / 策略问题，不是密钥配错 |

→ 继续重跑 Actions **无意义**；需旁路或换有国际连通的 CI/主机。

### 2.2 产品旁路：`DEPLOY_CI_PROVIDER=local_ssh`

| 项 | 说明 |
|----|------|
| 默认 | 仍为 `github_actions`，未改其它车道 |
| 确认后 | API 后台线程：临时 `git worktree` 检出 ref → `npm` 构建 → SSH/rsync → 可选远端重启 |
| 轮询 | `run_id=local-…`；确认卡区分「本机 SSH」文案 |
| 配置 | 主机 / 用户 / 私钥路径 / 远端目录 / 本机项目路径（系统配置热更新） |

关键实现：`deploy_local_ssh.py`、`deploy_prepare` / `deploy_confirm` 分支、`POST /deploy/poll`、Settings 字段、`LocalDevDeployGateCard.vue`。

### 已修（BUG / 安全）

| 现象 | 处理 |
|------|------|
| `RESTART_CMD` 可含 `;` `\|` `$()` | 白名单字符 |
| rsync `-e` / 远端 mkdir 未 quote | `shlex.quote` |
| 可能把 `.env` / `*.pem` 同步到预发 | rsync exclude |
| `app_path` 过浅（如 `/www/wwwroot`）+ `--delete` | 禁止浅路径 |
| ref 含 `..`；Host 写成 `IP:22` | 拒绝 |
| 私钥路径未验内容 | 须 `BEGIN … PRIVATE KEY` |
| 并发多路本机部署 | 同时仅 1 个 |
| poll 随意 `local-*` 字符串 | 严格 `local-`+12 hex |
| 设置页「未设置」易误解 | 「未保存」草稿态 + 部署区说明文案 |

### 仍存边界 / 技术债

1. **需重启 API** 后才加载今日全部加固（若进程仍是改代码前启动的）。  
2. Actions 路径对「纯国内机」仍不可用；文档已写旁路，未做国内 CI（CODING 等）。  
3. `StrictHostKeyChecking=accept-new`：首次连新主机仍有 MITM 面（与常见 CI 一致）。  
4. ERP 进程为 `nohup` + 脚本，非 systemd；宕机后需 `start-api.sh` 或再部署触发重启。  
5. 大改 **未 commit / 未推送 / 未发版**。  
6. P1-3d 部署后健康检查 / 查数验收未做。
