# 平台业务能力理解 — 测试用例（10 问）

用于验收「人话能力地图 / 场景表包 / 摸底报告」是否帮用户搞清：**表结构视角下平台业务能力有什么**。  

**范围澄清（验收必读）**
- 平台能力 = 中软 MES **数据库表结构**所反映的业务能力  
- 查工单 / 查排产 / 导入导出 = 助手 **模拟演示**，**不得**当成平台能力结论，也**不改**平台能力定义  

**不测**模拟查工单数据、不测导入确认（那些走原有用例）。

前置：已重启 API/Agent；已保存 `docs/MES业务/中软MES数据库表结构.md`。

判定约定：
- **P（通过）**：命中表结构能力工具；人话说明 + 代表表/场景；可点明「查/导是模拟演示」；不把模拟查/导写成平台能力
- **F（失败）**：用 `query_platform_data` 冒充平台能力总览；或声称「平台能力=能查工单/排产」

---

## TC-01 人话总览（表结构）

| 项 | 内容 |
|----|------|
| **测试问题** | 平台能干什么？给我一个功能总览 |
| **预期工具** | `list_platform_capabilities`（优先） |
| **期望要点** | ① 模块级人话摘要（仓储/品质/生产执行等）② 依据表结构 ③ **不把**查工单/排产/导入导出列为平台能力 |
| **通过标准** | 总览来自表结构能力地图；若提及查/导，须标明「模拟演示、不计入平台能力」 |

| **预期工具** | `list_platform_glossary` 和/或 `describe_platform_capability`（排产） |
