## 3. 自检

### 已修

| 现象 | 处理 |
|------|------|
| 冒烟先跑空目录会污染表结构缓存 | 先真实资料包，再负向 |
| 过程区查数预览英文 | `_result_detail` 优先中文 `display_rows` |
| DeepSeek 写码烧 token | 本机默认 Cursor Local，不再默认工具环 |
| 符号链接可把宿主机文件拷进沙箱 / 同步写出 | 拷贝跳过 symlink；同步只写普通文件；FS 工具拒绝链接 |
| Cursor follow-up 丢隔离 | `Agent.resume` 带上 `local=` + sandbox |
| import 修复失败仍同步 | 循环后统一 leftover 检查，不通过则中止 |
| 改了 settings 标签页面不变 | API 无 reload；杀残留 PID 后重启；前端再兜底 |
| 多套 `dev.sh` 占端口 + ∞ 终端 | 清 tail 与旧包装进程 |

### 仍存边界

1. 「当日完工」无日期筛参只能降级；接口侧无法凭空补参数。
2. Cursor Local ≠ Docker：靠 SDK sandbox + 提示词 + 同步闸门；恶意 Agent 越界仍可能尝试，落盘多半会被挡。
3. D↔B「改完自动跑查数」未做；闸门只动工程内 SQLite。
4. 控制台仍可能有 GitHub Cloud 写码费用（与本机 DeepSeek 分开记账）。
5. 今日改动尚未 commit。提交时排除 `.env`、`data/settings.json`、资料包密钥、`data/local_dev/`。
