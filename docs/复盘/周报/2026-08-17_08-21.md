## 4. 本周踩过的坑（如实）

- 现场库端口通 ≠ 产品该直连库；查数主路径必须是 MES HTTP。  
- 「0 域 0 表」不是没配资料包，是**解析器不认客户 Markdown 格式**。  
- WorkBuddy 登录成功仍可对 MES **401**——两套鉴权必须拆开讲。  
- DeepSeek 账单暴涨主因是**本机写码工具环**，不是查数扫库。  
- 写码加了库存 API 仍查不到：资料包 `entities` 未跟写 + 别名打到看板。  
- KPI「未完工 10 &lt; 急单 23」：limit / filters 数组序列化，不是业务真少。  
- 截图「视觉坏了」：设置里 Key 往往没坏，是**讨论注入文案误关视觉**或附件没带上。  
- 文件夹「只能勾不能下钻」：名字包在 `<label>` 里，点击只触发勾选。  
- 0.1.6 **先打包后扫安全** → 又修 6 项，dmg 需重打（已沉淀 checklist）。

5. **能值班运维**：紧急堆积、接口通不通、401、值班简报等场景已工具化。
