# 外部依赖降级演练手册（P1-08）

> 日期：2026-08-21  
> 目的：`PLATFORM_BASE_URL` / DeepSeek（对话）/ 智谱（视觉）/ Cursor Key 等强依赖**挂掉时**，产品应可解释降级，而不是静默假答或白屏。  
> 代码：`apps/agent/dependency_status.py`；冒烟：`make smoke-dependency-degrade`

---

## 1. 依赖与影响面

| 依赖 | 挂了会怎样 | 严重度 | 期望用户可见 |
|------|------------|--------|--------------|
| 对话 LLM Key（DeepSeek / `LLM_*`） | 无法建模型、对话失败 | **critical** | 明确提示去系统配置填 Key |
| `PLATFORM_BASE_URL` / MES 主机不可达 | 查数/摸底失败 | **critical** | 「无法连接 MES 接口…」类 error，不编造条数 |
| 资料包 / 可查对象未配 | 查数目录空 | **critical** | 「未配置可查对象…」 |
| 视觉 Key（智谱 / `VISION_*`） | 截图无【截图理解】 | **degraded** | 说明未配视觉；主对话仍可用 |
| `CURSOR_API_KEY` | Cloud 写 GitHub 不可用 | **optional** | 本机写码仍可；Cloud 就绪检查失败 |

文案常量集中在 `dependency_status`；改实现侧文案须同步常量 + 单测。

## 2. 自动化（无 LLM、无真外网）

```bash
# 仓库根
make smoke-dependency-degrade
# 或
cd apps/agent && python3 -m unittest test_dependency_status -v
```

覆盖：critical/degraded/optional 分级、LLM/平台不可达文案与 `agent.py` / `platform_api.py` 契约一致。

## 3. 人工演练清单（演示前 / 发版前各跑一轮）

在**单独终端**临时改配置，测完恢复；勿提交 `.env`。

| # | 操作 | 期望 |
|---|------|------|
| D1 | 清空对话 Key（或临时改错），重启 API，开对话 | 失败信息含「系统配置」/ `LLM_API_KEY` / `DEEPSEEK`；**不**空转假回复 |
| D2 | Key 正常，`PLATFORM_BASE_URL` 指到 `http://127.0.0.1:1`（不可达），问「工单列表」 | 工具返回含「无法连接 MES」；助手说明连不上，不报假工单号 |
| D3 | 不配视觉 Key，粘贴截图问「按这个改」 | 有「未配置视觉模型」类提示；仍可文字讨论写码 |
| D4 | 不配 `CURSOR_API_KEY`，确认卡选 GitHub 写码 | 就绪/创建任务失败可读；切 **本地目录** 仍可走本机写码 |
| D5 | 资料包未配 / 无 entities | 摸底/查数被挡，提示系统配置接入 MES |

勾选记在发版笔记；不必每次全跑 D1–D5，至少 **D1 + D2**。
