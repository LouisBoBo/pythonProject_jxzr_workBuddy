## 2. 今日做了什么

### 2.1 自动化任务栈（从零到可用）

- **后端**：`apps/automations/` — 调度器（30s tick）、执行器（Deep Agents）、落盘 store、RRULE、运行时防双跑、企微 delivery  
- **API**：`/api/automations` — 任务 CRUD、分页运行记录、立即测试  
- **前端**：`AutomationsView` — 定时任务 / 运行记录 Tab、模板创建、编辑对话框、运行详情抽屉  
- **配置**：系统设置「自动化任务推送」（Webhook Key、总开关、dry-run）  
- **在跑任务**：每日生产运营日报、每日 PCB+AI 新闻、每周工作周报  

### 2.2 生产日报（MES 真实数据）

- 模板 + Prompt：工单 / **设备稼动率** / 设备产出 / 工序良率 / 需关注  
- 排版对齐 PCB 早报：`**1. 标题**` + 要点 + 可选细分；查不到整段省略  
- **根因修复**：`device-utilization` 返回 `{labels, values}` 时序，查数层误当空列表 → Agent 跳过稼动率条  
  - `platform_api._timeseries_records_from_payload` zip 成行记录  
  - `query_present` 附带利用率汇总（平均/峰值/低谷）  
- 识别优化：无加粗 `1. 工单概况` 时 banner 从「今日精选」改为「生产日报」  

### 2.3 PCB 早报 + 企微推送

- `web_search.py`：智谱 Web Search，接入 Agent 工具链  
- `wecom_bot.py` + `delivery.py`：text / markdown 单条推送、重试、dry-run  
- `run_summary_text.js/py`：摘要解析（要点/细分/来源）、企微格式化、分隔线；修多条气泡 / 空行 / 趋势小结污染等体验问题  
- 周报：`repo_digest` 基于本仓 git 真实提交，禁止编造 MES 运维项  

### 2.4 体验与小修

| 现象 | 处理 |
|------|------|
| 编辑对话框 09:00、列表显示 08:00 | 自定义 RRULE 未命中预设时不再误回落 09:00 |
| 任务列表重复「+ 添加自动化」 | 去掉工具栏冗余按钮，保留顶栏入口 |
| 同刻多任务怎么跑 | 串行排队 + 全局 Agent 流锁；建议日报与新闻错开整点 |
| 运行记录会不会无限涨 | 补 **MAX_RUN_RECORDS=100**，超出按 `started_at` 删最旧 |

## 3. 写码自检（必做）

> 对照 [`.cursor/rules/cautious-coding-checklist.mdc`](../../../.cursor/rules/cautious-coding-checklist.mdc)

| 阶段 | 今日是否做到 | 备注 |
|------|--------------|------|
| 动手前：Happy path / 边界 / 失败表现 | ☑ | 稼动率时序、同刻调度、stream_busy |
| IO/网络：路径 under_root、tmp+replace、safe_http | ☑ | store 原子写；企微固定域名 + assert_http_url_allowed |
| 改已有函数：跑过调用链或单测 | ☑ | platform_api、store、wecom、schedule、web_search |
| 合并/同步：冲突规则已事先定好 | ☑ | 调度与用户对话共用 Agent 锁，串行排队 |
| 收工前：单测 + 一条用户路径 | 部分 | 单测绿；企微/日报依赖本机「立即测试」 |
| 打包前 | ☐ | **未打包**；代码已 commit |

### 已修（BUG / 安全）

| 现象 | 处理 |
|------|------|
| 设备稼动率「无数据」 | 时序 payload 正确展开 + 利用率汇总 |
| 调度 `stream_busy` 时 `break` | 改 `continue`，避免同 tick 跳过其他到期任务 |
| 自动化 `cwds` 可对任意目录跑 git | 限制在 WorkBuddy 仓库内 |
| Webhook 保存未校验域名 | settings 保存时 `normalize_webhook_key` |
| Webhook key 未 URL 编码 | `quote(key)` |
| 任务 ID 未统一校验 | `update/delete/get` 走 `_safe_automation_id` |

### 仍存边界 / 技术债

1. **Agent 单流锁**：多任务与用户对话互斥，第二个任务会顺延而非准点并行。  
2. 生产日报与 PCB 新闻若同刻，会串行等待并连发企微；建议错开整点。  
3. 运行记录超 100 条直接丢弃，无归档。  
4. 「立即测试」无频率限制（内网可接受）。  
5. 飞书写表 / 工单明细台账尚未做（**次日 08-28 继续**）。
