# 配置旋钮分层与接手指南（P1-07）

> 日期：2026-08-21  
> 目的：`config.py` + `settings.json` + `.env` 旋钮多，写清**解析顺序、谁可覆盖、改哪份文件**，降低误配与膨胀感。  
> 示例文件：仓库根 [`.env.example`](../../.env.example)

---

## 1. 三层配置（谁赢）

```text
UI 系统配置 → DATA_DIR/settings.json（白名单键）
        ↓ 非空优先
环境变量 ← 根目录 .env / 进程 env
        ↓
代码默认值（config.py / 各模块 getenv）
```

| 层 | 落点 | 热更新 | 典型用途 |
|----|------|--------|----------|
| **A. UI 覆盖** | `DATA_DIR/settings.json` | 保存后 `Config.reload_runtime()` | 桌面同事配 Key / ERP 地址 |
| **B. 环境变量** | `.env`、compose、systemd | 多数需重启 API | 运维、CI、功能开关 |
| **C. 代码默认** | `apps/agent/config.py` 等 | — | 安全默认（审码关、写确认开） |

解析实现：`apps/agent/settings_store.py` 的 `resolve_setting`；`Config` 里走 `_resolve` 的字段才吃 UI 覆盖。

**白名单**：仅 `settings_store.ALLOWED_KEYS` 可写入 UI；密钥进 `SECRET_KEYS`（落盘加密）。  
**勿提交**：`.env`、`data/settings.json`、资料包密钥。

---

## 2. 旋钮分层（`.env.example` 同结构）

| 层 | 含义 | 新人必看 |
|----|------|----------|
| **L0 启动必配** | 没它对话/查数起不来 | `DEEPSEEK_API_KEY`（或 `LLM_*`）、`PLATFORM_BASE_URL` |
| **L1 交付常用** | 登录、CORS、导出、资料包 | `AUTH_REQUIRED`、`CORS_*`、`MES_PROFILE_ID`、`EXPORT_*` |
| **L2 功能开关** | 默认关或有独立上线清单 | `IDE_REVIEW_*`、`CURSOR_DEV_*`、`READONLY_SQL_*`、`VISION_*` |
| **L3 运维调优** | 平时别动 | `WORKBUDDY_SSE_*`、`AGENT_RECURSION_LIMIT`、`CONTEXT_*`、`*_MAX_LINES`、HA `DATA_DIR` |

原则：**新旋钮默认进 L3 注释**；只有产品路径依赖才升到 L0/L1；功能默认关的进 L2。

---

## 3. 代码落点（勿混改）

| 域 | 主文件 | 备注 |
|----|--------|------|
| 对话 LLM / 平台 / 视觉 / 只读 SQL | `apps/agent/config.py` | `_resolve` = 可 UI 覆盖 |
| UI 白名单与加密 | `apps/agent/settings_store.py` | 加字段先改 `ALLOWED_KEYS` + Settings 页 |
| Cursor Cloud 写码 | `apps/cursor_dev/config.py` | `reload_config()`；Key 也可进 settings |
| 本机写码 | `apps/local_dev/config.py` | 与 cursor_dev 并列 |
| API 进程行为 | `apps/api/*` 内 `getenv`（CORS、SSE、流锁等） | 多数**仅**环境变量 |

---

## 4. UI 可覆盖键（摘要）

见 `ALLOWED_KEYS` 全文。常用：

- 对话：`LLM_API_KEY` / `LLM_BASE_URL` / `MODEL_NAME`（兼容 `DEEPSEEK_*`）
- 视觉：`VISION_*` / `ZHIPU_*`
- 平台：`PLATFORM_BASE_URL`、`MES_API_*`
- 写码：`CURSOR_API_KEY`、`CURSOR_DEV_*`（白名单内子集）
- 可选：`READONLY_SQL_*`、`MES_PROFILE_ID`、`IDE_GIT_*`

**不能**经 UI 改、须 `.env`：如 `IDE_REVIEW_ENABLED`、`WORKBUDDY_SSE_*`、`AUTH_REQUIRED`、CORS、探活沙箱等。

## 5. 加旋钮检查清单

1. ☐ 归属 L0～L3？默认值是否安全（关/收紧）？  
2. ☐ 仅 env 还是也要 UI？要 UI → `ALLOWED_KEYS` + Settings 表单项 + 中文说明  
3. ☐ 密钥？→ `SECRET_KEYS`  
4. ☐ 写入 `.env.example` 对应分层注释（勿只写进私下笔记）  
5. ☐ 若热更新：`Config.reload_runtime` / 对应 `reload_config` 是否覆盖
