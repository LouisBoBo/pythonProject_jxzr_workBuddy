## 2. 做了什么（交付物）

### 2.1 能力链路

```text
用户问「平台能干什么 / 仓储 / 工单到入库 / 导出报告」
        ↓
Skill：analyze-mes-schema（摸底，不是查实时数据）
        ↓
Tools（只读本地）：
  人话总览 → list_platform_capabilities
  模块详情 → describe_platform_capability
  术语     → list_platform_glossary
  字典/单表 → list_schema_* / describe_schema_table / analyze_schema_capabilities
  场景表包 → list_business_scenarios / get_scenario_table_pack
  报告     → export_schema_survey_report
        ↓
中文结论：人话能力 + 代表表 / 场景路径 / 报告路径
        ↓
边界提醒：表结构平台能力 ≠ 模拟查/导
```

### 2.2 关键路径

| 路径 | 说明 |
|------|------|

## 5. 经验与坑

1. **边界必须写进 Skill + 提示词 + 用例**，否则模型容易把「助手能查工单」说成「平台能力」。  
2. **Tool 参数要用 `Annotated` 注释**，仅靠 docstring `Args` 进不了 LLM schema。  
3. **`analyze_schema_capabilities(focus=…)` 曾按全量前缀统计**，聚焦无效；已改为按过滤后表聚合。  
4. **首页快捷问法**从查/导改成摸底问法后，空状态文案仍偏「管理 MES」，可后续微调，不影响验收。  
5. 报告与索引为本地产物：`data/exports` / `data/schema`（运行时，不入库）。
