## 1. 功能清单

### 1.1 登录与身份（F-AUTH）

| ID | 功能 | 说明 | 关键路径 |
|----|------|------|----------|
| F-AUTH-01 | ERP 登录 | 账号密码 + 企业下拉（江苏软云/江西中软/前海中软）经 API 代理 ERP | `apps/web/src/views/LoginView.vue`, `apps/api/routes/auth.py` |
| F-AUTH-02 | 会话保持 | Token 存 localStorage；`/api/auth/me` 校验 | `apps/web/src/auth.js` |
| F-AUTH-03 | 路由守卫 | 未登录跳转 `/login?redirect=` | `apps/web/src/router.js` |
| F-AUTH-04 | 401 退登 | API 401 清会话并回登录页 | `apps/web/src/api.js` |
| F-AUTH-05 | 开发旁路 | `AUTH_REQUIRED=false` 时 mock 用户 | `apps/api/routes/auth.py` |
| F-AUTH-06 | 用户隔离 | 历史/写操作按 JWT `sub` 归属，不信任展示名头 | `history.py`, `writes.py` |

### 1.2 对话与会话 UI（F-CHAT）

| ID | 功能 | 说明 | 关键路径 |
|----|------|------|----------|
| F-CHAT-01 | 流式对话 | SSE：`status` / `step` / `token` / `confirm` / `done` | `ChatView.vue`, `chat.py`, `agent_wrapper.py` |
| F-CHAT-02 | 过程面板 | 可折叠工具步骤时间线 | `ProcessPanel.vue` |
| F-CHAT-03 | 停止生成 | Abort 断开 SSE；保留半截 +「（已停止生成）」 | `ChatView.vue`, `api.js` |
| F-CHAT-04 | 继续 / 来吧 | 短句 enrich 原任务；停止气泡后新开答复 | `ChatView.vue` |
| F-CHAT-05 | 编辑重发 | 截断该条及之后消息再发送 | `ChatView.vue` |
| F-CHAT-06 | 复制消息 | 复制正文；去掉停止标记 | `ChatView.vue` |
| F-CHAT-07 | 代码块复制 | Markdown 代码块一键复制 | `ChatView.vue` |
| F-CHAT-08 | 输入区自适应 | 增高 + 超高滚动 | `ChatView.vue` |
| F-CHAT-09 | Markdown / 下载链 | `[下载: file]` → `/api/download/...` | `ChatView.vue` |
| F-CHAT-10 | 同步对话 API | `POST /api/chat` 阻塞回复（非主路径） | `chat.py` |

### 1.3 历史与线程（F-HIST）

| F-HIST-04 | 打开旧会话 | `GET /api/history/{id}` 加载消息 | `ChatView.vue` |
