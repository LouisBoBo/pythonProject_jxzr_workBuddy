## 3. 明确未完成 / 已知局限

1. **不是自动交付闭环**：不测、不合入、不部署；合 main 仍靠人。
2. **1:1 界面复刻未达标**：用户反馈从「50% 都没有」到「有点感觉」；色值、顶栏、占位链接等仍有差距。
3. **Cloud 服从固定分支**：多轮实仓落在 `hebo`，但仍依赖 Prompt + 配置，换仓/换 Key 需再抽检。
4. **意图路由**：启发式 + lane，极端短句（仅 URL、无动词）仍可能歧义。
5. **WorkBuddy 部分改动**：周内有推送，但截图/原图/UX 等当日改动是否全部入库，需再对 `git status`。
6. **同事零配置试点**：文档与就绪检查已有，尚未做大范围多人试用结论。

## 4. 本周踩过的坑（如实）

- 独立写码页不符合产品习惯 → 改回主聊天。
- 确认框过早、未澄清需求就开写 → 改为理解后再确认。
- 「改界面」被仓 URL 上下文拽进审核 → 对等路由硬修。
- 未勾选却开 PR、摘要双份「已完成」、双「写码完成」→ 逐项修。
- ECharts `height:100%` + autoresize 导致首页高度疯涨 → 固定图表高度。
- 任意路径读图外传 Cloud → 收紧 uploads。
