# 每日打开自动同步资料包

> 目标：用户只在乎「能查」，不必记得刷新接口目录。

## 行为

- **默认开启**（`MES_PROFILE_DAILY_SYNC=true`）
- 触发时机：
  1. API 进程启动后约 2 秒（桌面打开 / `dev.sh`）
  2. 前端拉取「MES 接入状态」`GET /api/mes-profile`（进设置或应用初始化）
- 每个资料包：**每天成功同步至多 1 次**
- 失败：静默；15 分钟冷却后可再试（本机 MES 晚于助手启动时仍能追上）
- 范围：从资料包 `api_base` 拉本机 OpenAPI，**合并**写入 `entities.json`（与写码后同步、手动 `refresh_mes_profile_from_runtime` 同一套）
- 仅 **localhost**；不打生产外网

## 关闭

```bash
MES_PROFILE_DAILY_SYNC=0
```

## 状态文件

`data/mes_profiles/{平台}/.daily_openapi_sync.json`  
成功含 `date` / `entity_count` / `added`；`GET /api/mes-profile` 响应里有 `daily_openapi_sync` 字段。

## 与写码后同步的关系

| 能力 | 何时 |
|------|------|
| 写码后自动同步 | 本机写码成功且动到 API/模型 |
| **每日打开同步** | 启动/打开应用，按日补齐漏网接口 |
| 对话手动刷新 | 用户说「刷新资料包」→ `refresh_mes_profile_from_runtime` |
