### 已修（BUG / 安全）

| 现象 | 处理 |
|------|------|
| 勾选文件名当目录前缀（`src` 吞掉 `src/...`） | 仅尾 `/` 目录前缀匹配；文件精确匹配 |
| `normalize_rel` 过宽 | 拒 `..` / `:` / `~` / 空字节 / 过深 |
| 范围确认超时 → 整单失败（范围内已同步） | 超时视为 `skip` 继续收尾；全越界且 skip 则明确失败 |
| confirm-scope 可重复/并发双写 | CAS：仅 `awaiting_scope` 且未决策；冲突 409 |
| 视觉异常原文进模型（可能含 Key/路径） | 只报错误类型；附件失败不列全路径 |
| 文件夹不能下钻 | label 与「进入」解耦 |
| 注入文案误关视觉 / 附件丢失 | 原话策略 + strong keep + pendingFiles 回退 |
| 意图含糊瞎猜改法 | 澄清卡（按图修改 vs 复原） |
