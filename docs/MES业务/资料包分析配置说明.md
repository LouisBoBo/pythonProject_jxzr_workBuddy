# 资料包分析配置说明（换平台通用）

> 数据分析**不写死**某一套 MES 的实体 id、路径或状态值。  
> 换平台：新建/切换资料包 → 导入 OpenAPI + 按需覆盖配置 → 同一套工具即可用。

## 配置优先级

```text
内置 metrics_default.json（通用口径）
  + metric_packs（仅当资料包声明，如 pcb）
  + mes_profiles/{平台}/metrics.json（按 id 覆盖/停用）
```

```text
内置 group_by / brief 默认
  ← profile.json.analysis / metric_packs
  ← analysis.json（同目录，可整段覆盖）
```

## 必做（每个平台）

1. **系统配置 → MES 接入**：平台名称、表结构、OpenAPI、接口账号  
2. 确认 `list_platform_entities` 非空  

## 建议（贴合该厂口径）

### `metrics.json`（覆盖 entity_hints / 枚举）

```json
{
  "version": 1,
  "metrics": [
    {
      "id": "wip",
      "label": "在制",
      "entity_hints": ["工单", "制造订单", "MO"],
      "aliases": ["在制", "WIP"],
      "definition": "本厂：状态=生产中",
      "include_in_brief": true,
      "clauses": [
        {
          "field_role": "status",
          "field_hints": ["Status", "状态"],
          "include_values": ["生产中", "Producing"]
        }
      ]
    },
    { "id": "aoi-fail-topn", "disabled": true }
  ]
}
```

- **覆盖**：同 `id` 整段替换内置  
- **停用**：`{ "id": "xxx", "disabled": true }`  
- **禁止**写死其它厂的实体英文 id（如目录没有就不要写 `work-orders`）

### `analysis.json`（分组与简报）

```json
{
  "group_by_labels": ["状态", "优先级", "车间"],
  "brief_metric_ids": ["wip", "urgent-unfinished", "completed-today"],
  "brief_metric_limit": 4,
  "metric_packs": ["pcb"]
}
```

| 字段 | 含义 |
|------|------|
| `group_by_labels` | 分析简报尝试的分组「角色名」；记录里没有对应列则跳过 |
| `brief_metric_ids` | 简报优先跑的口径 id |
| `metric_packs` | 加载内置可选包（当前：`pcb`） |
| `dashboard_template` | 默认看板 id（内置 `pcb_ops`；可用资料包 `dashboards/{id}.json` 覆盖） |
| `value_labels` | 枚举英文码 → 中文展示（如 `pending`→`待开工`）；**仅影响表格/图表类目**，查数 filters 仍传 API 英文码 |
| `analysis_demos` | 可选：覆盖/禁用看板编排，如 `{ "pcb-ops-board": { "enabled": false } }` |

也可把 `metric_packs` / `analysis` 写在 `profile.json` 里。

### PCB 运营看板编排（可选）

对话说「打开PCB运营看板」→ `run_analysis_demo`（简报 → 多图看板 → 急单样例）。  
普通「值班简报 / 产线日报」仍走 `run_ops_scene`，不受影响。

- 内置：`demo_playbooks/pcb_ops_board.json`
- 资料包覆盖：`demos/pcb_ops_board.json`
- 关闭：`analysis.json` → `"analysis_demos": { "pcb-ops-board": { "enabled": false } }`

### 运营看板（可选）

对话「打开 PCB/品质运营看板」→ `render_analysis_dashboard`。  
内置模板：`apps/agent/tools/query_tool/dashboard_templates/pcb_ops.json`（按 hints 绑定，不写死实体 id）。  
资料包可放 `dashboards/pcb_ops.json` 覆盖卡片；缺接口的卡会标缺口，不影响其它查数。

### `ops_scenes.json`

按 id 覆盖场景别名、是否 `include_chart`；`disabled: true` 可关掉某场景。
