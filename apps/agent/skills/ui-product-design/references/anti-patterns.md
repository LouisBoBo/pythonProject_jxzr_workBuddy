# UI 反模式速查（实现侧）

与 `SKILL.md` 配套；Cloud / 讨论阶段遇到下列情况直接判不合格。

| 反模式 | 为何差 | 改法 |
|--------|--------|------|
| 业务页 = 首页换标题 | 无产品身份 | 独立构图；换主图元与首屏结构 |
| 双半圆 gauge 完全相同 | 像占位符 | 区分指标语义、辅色、刻度文案 |
| el-card KPI 一行三卡 | 模板感 | 色块层级 / 主次面积 / 自定义 CSS |
| 霓虹描边 + 紫辉光 | AI 默认丑 | 少强调色、中性色阶、弱描边 |
| 表+图同权抢视线 | 嘈杂 | 一主一辅；表可沉底 |
| 为好看加无关模块 | 范围漂移 | 只做需求内模块 |
