# 操作指南：查生产数据 → 飞书多维表格

> 配套方案：[生产数据企微消息与飞书多维表格方案.md](./生产数据企微消息与飞书多维表格方案.md)  
> 与企微推送**互不干涉**：本指南只开写表即可。

---

## 你要完成的 5 步

### 第 1 步：飞书开放平台（应用凭证）

1. 打开 [飞书开放平台](https://open.feishu.cn/) → 创建**企业自建应用**。  
2. **凭证与基础信息**：复制 **App ID**、**App Secret**。  
3. **权限管理**：搜索并开通（按控制台实际名称勾选）：  
   - **新增记录**（`base:record:create`）— 写表必开  
   - 若表格在 **知识库 wiki** 链接里：再开 **获取知识空间节点**（wiki 相关），便于把 wiki token 解析成真实 app_token  
4. **版本管理与发布** → 创建版本 → 申请发布（测试企业可直接可用）。  

> 列名不必一字不差：写表前会拉取飞书表头并宽松匹配（`平均稼动率%` ↔ `平均稼动率` 等）。若开放平台有「查看字段」权限更稳。  

### 第 2 步：建多维表格并授权应用

1. 飞书里新建**多维表格**（空表即可，**不必手写表头**；首次写表时系统会自动创建日期/数字等列）。  

| 系统会自动创建的列 | 类型 |
|------|----------|
| 日期 | 日期 |
| 在制工单 | 数字 |
| 未完工 | 数字 |
| 紧急未完工 | 数字 |
| 平均稼动率 | 数字 |
| 日产合计 | 数字 |
| 良率下限 | 数字 |
| 良率上限 | 数字 |
| 需关注摘要 | 文本 |

> 不要把列名当成「行」填进「文本」列——那是数据行，不是表头。若表里已有这种误填行，直接删掉即可。

2. 表格右上角 **… → 更多 → 添加文档应用**（或「添加应用」）→ 选中你的自建应用 → 可编辑。  
3. 从浏览器地址栏复制（也可把整段链接贴进 WorkBuddy，系统会自动截取）：  
   - **app_token**：`/base/basc…` 后面一段；若是 `/wiki/…` 链接，可先填 wiki 节点 token（系统会自动解析），或点「在多维表格中打开」后改用 `basc…`  
   - **table_id**：URL 参数 `table=` 的值（`tbl` 开头）；**不要**填 `pageId` / `view=`  

### 第 3 步：ZR WorkBuddy 系统配置

1. 打开 **系统配置 → 自动化推送**（分组含「飞书多维表格同步」）。  
2. 填写：  
   - 飞书应用 App ID  
   - 飞书应用 App Secret  
   - **开启飞书多维表格同步** = 开  
3. 首次联调可先开 **写表联调模式**（只打日志不真写），确认后再关。  
4. **保存并热更新**。  

### 第 4 步：创建/编辑自动化任务

1. **自动化任务** → 可用模板「每日生产运营日报」，或新建自定义任务。  
2. **推送到企业微信**：可关（只验证写表时建议关）。  
3. **同步到飞书多维表格**：开。  
4. 填写 **app_token**、**table_id**。  
5. 保存。  

开启写表后，系统会在执行时自动追加 `bitable_json` 输出要求；摘要末尾会带结构化行数据。

### 第 5 步：立即测试验收

1. 任务卡片 → **立即测试**（勿与用户对话抢流）。  
2. **运行记录** → 看：  
   - 状态成功  
   - **写表**列 = 已写入（失败则悬停看原因）  
3. 打开飞书表 → 应多 **1 行**昨日汇总。  
4. （可选）在表里建「稼动率折线 / 产量柱状」视图做演示。

## 常见失败对照

| 现象 | 处理 |
|------|------|
| 写表 = 未写表 / skipped | 总开关未开，或任务未开同步 |
| 未配置 App ID/Secret | 回系统配置填写并保存 |
| 摘要中未找到 bitable_json | 再测一轮；确认任务已开写表（会注入输出块） |
| 飞书权限 / 应用未加入文档 | 表里重新「添加文档应用」；权限已发布 |
| `91403 Forbidden` | 表内未给应用「可编辑」；或 wiki token 未解析成功 |
| `91402 NOTEXIST` | app_token / table_id 错（pageId 不能当 table_id） |
| `FieldNameNotFound` | 列名不一致（如写成「平均稼动率%」而表里是「平均稼动率」） |
| 字段不存在 | 列名须与默认映射一致（或后续再改 field_map） |
| 日期写入异常 | 飞书「日期」列类型；不要用文本列名却建了单选 |

## 和企微的关系

| 开关 | 作用 |
|------|------|
| 推送到企业微信 | 只控制群消息 |
| 同步到飞书多维表格 | 只控制写表 |

可只开写表验证；现网生产日报可继续只开企微。
