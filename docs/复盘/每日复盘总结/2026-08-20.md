## 2. 今日做了什么

### 2.1 方案与文档（上午）

- 定调：**HTTP + metrics 为主**；只读 SQL 默认关、白名单可开；图表只渲染已取回 series，不直连库。
- 落地文档：验收话术 A01–A18、资料包分析配置、图表 MCP 说明、通用 BI / PCB 里程碑（M0–M4）、每日打开同步说明。
- M0：江西中软对照 entities / OpenAPI / schema，缺口勾选完成。

### 2.2 分析引擎与看板（主线）

| 能力 | 说明 |
|------|------|
| 单图 | `analysis_chart.py` → SSE `chart` → `AnalysisChartCard.vue`（bar/line/pie；可 MCP） |
| 看板 | `analysis_dashboard.py` + `dashboard_templates/pcb_ops.json`；单卡失败不拖垮，缺卡诚实缺口 |
| 演示编排 | `analysis_demo.py` + `demo_playbooks/pcb_ops_board.json`；话术「打开PCB运营看板」 |
| 运营呈现 | `ops_presentation.py`：顶栏 KPI、深色皮肤、点图 `drill` |
| 指标包 | `metric_packs/pcb.json` + 资料包 `analysis.json` 启用 packs |
| Skills | `analyze-mes-data` / `analyze-pcb-mes`；查询 Skill 补充分析路由 |
| 只读 SQL | `readonly_sql.py` 骨架（默认关） |

### 2.3 口径与数据正确性

- **filters 数组**：原 `str(list)` 导致组合过滤 0 条 → `_list_query_string` 按重复 key 展开。
- **未完工 KPI &lt; 急单**：KPI 拉取 limit 过小 + 笛卡尔积上限过紧 → limit 抬高、组合上限放宽并写 caveat。
- **默认 limit 20→50**：`query_metric` / `query_platform_data` / `run_ops_scene` / `present_query_result`；紧急未完工 23 条可一页看全（旧会话仍可能显示 20/23）。
- **枚举中文**：`value_labels.py` 管展示；filters 仍传英文码。

### 2.4 资料包每日同步

- `mes_profile_daily_sync.py`：按日打开触发同步节奏（与写码后 `mes_profile_sync` 互补）。
- API / settings 接线；单测 `test_mes_profile_daily_sync.py`。

### 2.5 前端体验与晚间修稳

| 现象 | 处理 |
|------|------|
| 切会话图表消失 | `persistableMessages` 已存图，但 `loadSession` 未还原 → 恢复 charts/dashboards（含 kpis/gaps）；卸载前冲刷流式图并 `persistSession` |
