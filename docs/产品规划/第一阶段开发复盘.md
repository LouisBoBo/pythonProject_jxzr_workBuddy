## 3. 分模块回顾

### 3.1 Monorepo 迁移与工程化

**做了什么**

- 将原 mes-client 能力收拢为 `apps/agent` + `apps/api` + `apps/web`
- 统一 `.env` / `.env.example`，根目录 `run.py` 作薄入口
- `scripts/dev.sh` / `stop.sh`、`Makefile`、`docker-compose.yml`（API/Web 分容器，ERP 外挂）
- 导入路径修正：`agent_wrapper` → `agents.agent`

**意义：** 一个仓库维护 Agent 与前后端，避免双份代码和端口混乱。

### 3.2 平台查询与实体目录

**做了什么**

- 查询走白名单，不是平台全部 API
- `entities.json` + `entity_catalog.py`：实体 id、path、别名、动态系统提示词
- 工具：`list_platform_entities` / `get_platform_summary` / `describe_entity` / `query_platform_data`
- 导入导出与查询共用实体 id（`file_ops`）
- 修复「查生产计划却返回工单」：别名（生产计划 / 排产 / 排程等）+ 提示词规则 + 最长匹配

**维护方式：** 改 `apps/agent/tools/query_tool/entities.json` 后**重启 API**（进程内单例，不热更目录）。

**踩坑：** 实体映射与 prompt 缓存在进程内存；别名过短或冲突会导致实体选错。

### 3.3 Deep Agents Skills

**做了什么**

- `FilesystemBackend(virtual_mode=True)` + `skills=["/skills/"]`
- 内置：`query-mes-data`、`import-export-data`、模板 `skill-template`
- 约定：Skills = 可选剧本；Tools / `entities.json` = 硬能力

**踩坑：** Agent 会 `read_file` 读 Skill，过程区若 dump 全文会很吵（后期已摘要化）。

### 3.4 Middleware

**做了什么**

| 中间件 | 默认 | 作用 |
|--------|------|------|
| `MesAuditToolMiddleware` | 开（`ENABLE_AUDIT_MIDDLEWARE`） | 工具调用审计日志 |
| `MesEntityGuardMiddleware` | 关（`ENABLE_ENTITY_GUARD=true` 开启） | 问 A 实体却调 B 时硬拦截 |

配套指南与单测路径已留在 `apps/agent/middleware/`。

### 3.5 API 与 Web

**API**

- 同步 `/api/chat`、流式 `/api/chat/stream`
- 历史、上传、文档转换、导出静态挂载
- CORS、健康检查、开发 reload（可监听 agent 目录）

**Web**

- Vue 对话页：发送、流式正文、附件、历史会话
- 处理过程面板（见下节）
- 开发态流式可直连 `8765`，减轻 Vite 代理 SSE 缓冲

### 3.6 处理过程 / 流式（末期加项）

**做了什么**

- SSE：`status` / `step` / `token` / `done` / `error`
- 过程区：时间线卡片（输入参数、结果摘要、样例预览），与正文气泡分离
- 多轮工具间隙 waiting、正文前 generating；摘要避免 Skill/JSON 刷屏

**现状：** 能用、可读；「丝滑思考流」未达标，属体验债，二期再打磨。详见需要时可单开体验迭代，不阻塞主功能。

### 3.7 协作与发布

- 代码推至 GitHub 分支 `hebo`（初始提交 `ab954af` 及后续本地改动）
- `.env` 不入库；密钥走环境变量

## 4. 主链路（心智模型）

```text
用户自然语言（如「查一下生产计划」）
    → Web :5180
    → API :8765（AgentRunner.stream_chat / chat）
    → Deep Agent（Tools + Skills + Middleware）
    → entity 解析（别名 → production-plans）
    → PLATFORM_BASE_URL/api/v1/{path}/
    → 摘要进过程区 + 正文流式回前端
```

能力边界：

- **能查：** `entities.json` 登记过的实体  
- **不能查：** 未登记的平台接口（需先加目录）  
- **Skill：** 教怎么做，不替代 Tool  
- **Middleware：** 横切强制策略，不替代业务 Tool

## 5. 问题与经验

| 类别 | 问题 | 经验 |
|------|------|------|
| 实体选错 | 「生产计划」打成工单 | 别名 + 提示词规则要一起做；必要时实体守卫 |
| 配置热更 | 改 `entities.json` 不生效 | API 需重启；文档写清 |
| 双份工程 | 旧 mes-client 与新仓并存 | 迁移后禁用旧入口 |
| LLM 余额 | DeepSeek 402 | 联调要有备用 key / 提供商 |
| SSE 体验 | 代理缓冲、多轮空窗 | DEV 直连 + flush；空窗用状态文案，别假装「已生成」 |
| 过程信息 | 太干 vs 太吵 | 摘要 + 预览折中；完整 dump 不要默认展开 |
