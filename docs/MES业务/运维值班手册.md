# 运维值班手册（能力块 C）

对齐 [`MES懂行助手四块能力方案.md`](../总览/MES懂行助手四块能力方案.md) **C1–C4（P0）**。  
实体、字段、状态值一律以**当前 MES 资料包**为准，不写死某一套 MES。

对话入口：`list_ops_scenes` / `run_ops_scene`（Skill：`ops-query-playbook`）。

---

## 1. 值班场景一览（≥8）

| # | 场景 id | 用户说法（例） | 标准链 | 验收要点 |
|---|---------|----------------|--------|----------|
| 1 | `urgent-backlog` | 紧急工单 / 急单堆积 | 口径查询 → 状态汇总 → 可选导出 | 复述口径（urgent+high ∩ 未完工）；禁止只筛 urgent |
| 2 | `wip-snapshot` | 在制有多少 | 在制口径 → 可选汇总/导出 | 条数与 in_progress 类一致 |
| 3 | `unfinished-snapshot` | 未完工 | 未完工口径 | 不含已关闭/已完工 |
| 4 | `status-breakdown` | 按状态各多少 | 轻量汇总 | 分组字段来自真实列 |
| 5 | `export-list` | 导出清单 | export | 绝对路径 + 行数 |
| 6 | `api-health-sandbox` | 接口通不通 | 指引沙箱探活六步 | **默认不打生产** |
| 7 | `write-audit-who` | 谁导入了 | 写审计 confirmed | 近 30 天窗；非 ERP 表 |
| 8 | `write-audit-failed` | 导入失败 | 写审计 failed | 重试须确认卡 |
| 9 | `login-mes-auth-help` | 401 / Token | 引导 | WorkBuddy 登录 ≠ MES 接口账号 |
| 10 | `catalog-empty-help` | 没可查对象 | 引导 MES 接入 | 不编造目录 |
| 11 | `ops-diagnose` | 查不到数据 / 故障排查 | 就绪状态+日志分支 | 不写 MES、不泄密 |
| 12 | `ops-daily-brief` | 值班简报 | 当前能绑定的口径摘要 | 绑不上就跳过 |

资料包可放 `ops_scenes.json` 按 id 覆盖/停用场景。

---

## 2. 异常/紧急单标准链（C2）

```text
用户：紧急工单有哪些 / 急单堆积
  → run_ops_scene(scene="urgent-backlog")
  → （需要文件）run_ops_scene(..., export=true)
  → 若要改状态：说明须确认卡，禁止默写
```

等价拆步：`query_metric("紧急未完工")` → 看表 → `export_platform_data`（或场景内导出）。

**口径**：紧急 **或** 高优先级，且未完工/未关闭。  
**禁止**：只用 `filters={"priority":"urgent"}`（会漏掉 high，且可能带上已完工）。用户明确说「只要 urgent 这一档」时才可单筛。

## 3. 接口健康（C3）

| 问题 | 走哪条线 |
|------|----------|
| MES **查数**通不通 | 资料包 + 接口账号 → `query_platform_data` / `run_ops_scene` 查清单 |
| **OpenAPI 文档**接口测通不通 | `build_api_catalog` → `probe_api_catalog()`（**sandbox**）→ 报告 |
| 网关访问日志里哪些错 | `import_external_api_logs` → `analyze_api_errors_from_logs` |

**何时可对预发/生产探活（live）**

- 默认：**不可以**。文档测试一律 sandbox。  
- 仅当用户**明确**说「打生产 / 真实出站只读核验」时才 `mode=live`。  
- live **禁止**写方法探活。  
- 配置错误（无 docs、沙箱不可达）须明确拒绝，不要静默改打生产。

---

## 4. 写操作确认与审计回看（C4）

| 用户说法 | 工具 |
|----------|------|
| 谁导入了 / 谁写过 | `run_ops_scene("write-audit-who")` 或 `query_write_audit` |
| 导入失败原因 | `run_ops_scene("write-audit-failed")` |
| 要导入/改数据 | Skill `import-export-data` + **确认卡**；未确认零副作用 |

审计数据来自助手 `data/writes/audit.jsonl`，**不是** ERP 业务表。

---

## 5. 手工冒烟（对话）

1. 「紧急工单有哪些」→ 清单 + 口径说明  
2. 「把紧急单导出来」→ `export=true` 或导出工具，有路径  
3. 「谁导入了文件」→ 审计表 + 近 30 天说明  
4. 「接口通不通」→ 区分查数就绪 vs 沙箱探活；不默认 live  
5. 「MES 401」→ 引导补接口账号，不回显密码  

自动化：`python -m unittest tools.query_tool.test_ops_playbook`（在 `apps/agent`）。
