# 试点「天天 20 句」验收（P1-01）

> 目的：把试点厂**每天该能问通**的话术收成一张可勾选表，避免能力散落在多份文档、打绿靠感觉。  
> 范围：A 懂平台 + B 查数分析 + C 值班（**不含** D 写码；写码见领导演示清单）。  
> 资料包示例：江西中软；换厂后实体 id / 状态值以当前目录为准。  
> 细则仍以：[`MES摸底固定话术.md`](MES摸底固定话术.md)、[`PCB数据分析验收话术.md`](PCB数据分析验收话术.md)、[`运维值班手册.md`](运维值班手册.md)、[`实施高频场景清单.md`](实施高频场景清单.md)。

**判定**

| 符号 | 含义 |
|------|------|
| **P** | 工具链对、口径说清、条数/图与工具一致、无编造 |
| **F** | 错工具、编造 KPI、页内当全库、无接口仍出假数 |
| **GAP** | 当前资料包无接口/半有 caveat——**诚实缺口也算本句通过**（须说清缺口，禁止充数） |

**规则**：能力绑在现场 API 齐不齐；**GAP 要推动补 OpenAPI / 口径 / 只读 SQL**，不要靠话术硬撑。
