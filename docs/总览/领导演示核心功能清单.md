# ZR WorkBuddy · 领导演示核心功能清单

> 日期：2026-08-20  
> 产品：**ZR WorkBuddy**（网页 / 桌面同一套能力）  
> 定位：对已有 MES —— **读懂 → 查得动 → 运维帮得上 → 需要时能改代码**；人不离开同一对话入口。  
> 联调建议：资料包「江西中软」+ MES API 可达；**新开一轮对话**再演示。  
> 详细验收：[`PCB数据分析验收话术.md`](../MES业务/PCB数据分析验收话术.md)、[`MES摸底固定话术.md`](../MES业务/MES摸底固定话术.md)、[`运维值班手册.md`](../MES业务/运维值班手册.md)

---

## 0. 开场 30 秒（建议话术）

> WorkBuddy 不是另做一套 MES，而是挂在现有 MES 上：  
> **A 读懂资料包 → B 对话查真数/出图 → C 值班标准化 → D 确认后改代码。**  
> 换厂只换资料包与接口账号，不改产品写死实体。

| 能力块 | 一句话价值 | 演示看点 |
|--------|------------|----------|
| **A 懂平台** | 少翻文档，说清模块/表/链路 | 人话能力地图，不编实时条数 |
| **B 数据分析** | 查真数、指标口径、出图、看板 | 急单清单 + PCB 运营看板 + 点图下钻 |
| **C 协助运维** | 值班话术固定化、写操作可审计 | 急单场景 / 值班简报 / 确认卡 |
| **D 加功能** | 本机或 GitHub 写码，确认后才改仓 | 选仓 → 确认卡 → 过程可停 |

## 1. 演示前检查（5 分钟）

| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | 已登录 WorkBuddy | 进入对话页 |
| 2 | **系统配置 → MES 接入**：资料包已激活 | 可查对象 > 0 |
| 3 | 已上传 OpenAPI + 表结构（或资料包齐全） | `inspect` 不报缺主件 |
| 4 | MES 接口账号可用（与 WB 登录账号分开） | 能查到工单真数 |
| 5 | MES/ERP 样例或现场 API 可达 | 例如联调 `:8009` |
| 6 | （可选）演示写码：本机目录或 Cursor Key 已配 | D 段才需要 |
| 7 | 新开会话 / 清空干扰线程 | 避免旧消息抢戏 |

**负向预备（领导追问时用）**：未配 MES 账号时应挡查数；空资料包不出假图；不编造良率。

## 2. 推荐演示路径（约 15～20 分钟）

> 时间紧只走 ★；充裕再补「加分项」。

| 顺序 | 块 | ★ 必演话术 | 领导应看到 | 约时 |
|------|----|------------|------------|------|
| ① | 配置 | （口述）系统配置里挂资料包 + 接口账号 | 「换厂靠配置，不改代码」 | 1′ |
| ② | A | 「MES 系统能干什么？」 | 模块能力地图；**不说**已查到 N 条 | 1.5′ |
| ③ | A→B | 「今天有多少工单？」 | **自动去查数**，不拿文档瞎编 | 0.5′ |
| ④ | B | 「紧急未完工有哪些？」 | 中文表 + 口径（紧急/高 ∩ 未完工）+ 条数自洽 | 2′ |
| ⑤ | B | 「按状态各有多少，出个饼图」 | 汇总 + 对话内饼图 | 1.5′ |
| ⑥ | B | 「打开 PCB 运营看板」 | 深色看板 + 顶栏 KPI + 多图；点急单饼图出明细 | 3′ |
| ⑦ | C | 「出一份值班简报」 | 口径摘要 + 分布；绑不上的指标跳过 | 1.5′ |
| ⑧ | B | 「把急单导出来」 | 绝对路径 + 行数 | 1′ |
| ⑨ | D | 「在本机工程加一个 XXX 列表页」（短需求） | 选仓/确认卡 → 过程区步骤 → **未确认不落盘** | 3′ |
| ⑩ | 收尾 | 切走再切回刚才出图的会话 | **图表还在**（历史持久化） | 0.5′ |

**收尾一句话**：  
> 同一对话入口覆盖懂厂、查数分析、值班、改码；数据走 MES 接口与口径包，无数据就诚实缺口，不编 KPI。

## 5. 领导常问 · 标准答法

| 问题 | 建议答法 |
|------|----------|
| 和 BI 大屏什么关系？ | 对话是入口，看板是阵地；不做替代 MES 的独立 BI 产品。 |
| 数据从哪来？ | 主路径 MES/ERP **HTTP API** + 资料包口径；只读 SQL 默认关。 |
| 换一家工厂怎么办？ | 换资料包（表结构 + OpenAPI + 账号），指标/看板可配置覆盖。 |
| 会不会编造数据？ | 无接口/无分母就报缺口；禁止常识冒充 KPI。 |
| 会不会乱改生产库？ | 写操作与写码均须确认卡；默认不写生产库。 |
| 写代码会不会直接上线？ | 只到本机预览或工作分支，合主干与发布仍人工。 |
| 通用 BI 做到哪了？ | 轻量分析 + PCB 运营看板已可演示；服务端聚合/时间维（M1）下一阶段。 |
