## 怎么读分册（给开发 / 深入）

每篇统一结构（与 [11-自动化任务](./11-自动化任务.md) 同体例）：

1. **开篇** — **一句话**（是什么）+ **不是**（防概念混淆）  
2. **实现原理** — 人话讲清「配什么 / 干什么 / 达到什么效果」+ **技术落点 / 技术点表**（模块、函数）  
3. **实现流程** — 每步：**人话** → 调用链 → **技术点表**；含排查表  
4. **技术及用法** — 模块 → 关键函数 → 干什么；配置项速查  
5. **后续扩展** — 可做 / 不要做  
6. **自测路径** — 2～4 步可点验收  

略懂技术建议阅读顺序：**00 → 你关心的功能编号**；原理和流程两节是重点。
