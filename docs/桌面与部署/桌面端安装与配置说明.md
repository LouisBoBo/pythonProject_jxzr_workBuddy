# ZR WorkBuddy 桌面端安装与配置说明

> 目标：**安装后配置 Key 即可使用**（无需再装 Python / 克隆仓库）。  
> 方案细节见 [`桌面端与网页双交付方案.md`](桌面端与网页双交付方案.md)。  
> 网页开发仍用 [`scripts/dev.sh`](../../scripts/dev.sh)。

---

## 1. 同事怎么用（安装包）

1. 从内部分发拿到安装包：
   - macOS：`ZR WorkBuddy-*.dmg` 或 `.zip`
   - Windows：`ZR WorkBuddy Setup *.exe`
2. 安装并打开 **ZR WorkBuddy**  
   - macOS 若提示「无法验证开发者」：在 Finder 中**右键 → 打开**一次即可。
3. 进入 **系统配置**，填写并保存：
   - 对话模型：`LLM_API_KEY` / `LLM_BASE_URL` / 模型名  
   - 可选：视觉模型 Key（截图理解）  
   - （正式对接 ERP 时再用环境变量 `PLATFORM_BASE_URL`；系统配置页暂不展示该项）
4. 返回登录页登录 → 对话 / 本机写码等与网页一致。

说明：

- **不会**内置任何人的 Key；配置写在本机用户目录（Electron `userData/data/settings.json`）。
- ERP 暂时不可达时，登录会回落到内置探活沙箱（可先体验登录，业务数据仍依赖真实 ERP）。
- 「同步后自动预览」仍需要本机 **Node 18+**；只聊天 / 登录可不装 Node。
- **GitHub 审码拉仓**：默认内置 HTTPS 镜像回退（优先镜像）；可在「系统配置 → Git 审码拉仓」改前缀，或填 `off` 关闭。不能内置 VPN。

## 2. 维护者怎么打完整安装包

在仓库根目录：

```bash
./scripts/package-desktop.sh
# 或：
./scripts/package-desktop.sh mac
./scripts/package-desktop.sh win
```

流水线：

1. `apps/web` → `dist`  
2. `desktop/py/build_runtime.py`：下载 **python-build-standalone** → 建 venv 装 `requirements.txt` → 复制 `apps/*` → 生成 `desktop/runtime/bin/workbuddy-*`  
3. `electron-builder` → `desktop/release/`（把 `runtime/` + `web-dist` 打进安装包）

说明：不使用 PyInstaller 冻结合 AI 依赖（易误拉 torch/nltk 导致启动失败）；安装包自带可重定位的 CPython，同事机**不必**预装 Python。

加速（已有产物时）：

```bash
SKIP_WEB=1 SKIP_RUNTIME=1 ./scripts/package-desktop.sh   # 只重打 Electron
SKIP_WEB=1 ./scripts/package-desktop.sh                  # 只重建运行时 + 打壳
```

**禁止**打入：`.env`、真实 Key、`data/local_dev/sandboxes` 等开发数据。

请在**目标架构**的机器上打包（本机 `uname -m`：Apple Silicon 打 arm64，Intel/Rosetta 打 x86_64）。

## 3. 开发态（未打包）

本机有仓库时：

```bash
./scripts/run-desktop-dev.sh
```

优先使用已冻结的 `desktop/runtime/*`（若存在），否则回退系统 `python3` + 源码。

---

## 4. 与网页对照

| | 网页 | 桌面安装包 |
|--|------|-----------|
| 分发 | 浏览器打开服务 | dmg / exe |
| 运行时 | 本机 `dev.sh` / 服务器 | **包内** API + 沙箱 + 前端 |
| 配置 | `.env` 或系统配置 | **仅系统配置**（推荐） |
| 数据目录 | 仓库 `data/` | 用户目录 `userData/data` |
