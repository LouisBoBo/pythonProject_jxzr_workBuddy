# 实施高频场景清单（查 / 导）

实体与字段一律以**当前 MES 资料包可查对象目录**为准（对话里先 `list_platform_entities`），不要写死演示工单/排产。

换平台后 id、路径、状态值都会变；本页只给话术模板。

---

## 话术模板（把「某对象」换成目录里的中文名/别名）

| # | 用户说法（示例） | 期望工具 | 备注 |
|---|------------------|----------|------|
| 1 | 查一下某对象 / 看看有哪些某某 | `query_platform_data` | 英文 id 来自当前目录；回复含中文名、条数、中文列 |
| 2 | 查状态是 pending / 进行中的某对象 | `query_platform_data(..., filters={...})` | filters 必须下发给 MES；字段名以 `describe_entity` 为准 |
| 3 | 某对象按状态各有多少 | `summarize_platform_data` | 分组字段必须是返回记录里真实存在的列 |
| 4 | 把某对象导出来 / 导出成 Excel | `export_platform_data` | 回复绝对路径 `file` + 行数 `rows` |
| 5 | 异常 / 紧急 / 高优先级 | 对应实体 + `filters` 或 `query_metric` | 无该字段时如实说明 |
| 6 | 在制 / 未完工 / 紧急未完工 / 当日完工 | `query_metric` 或 `run_ops_scene` | 口径绑定当前目录 |
| 7 | 紧急堆积 / 谁导入了 / 接口通不通 / 401 | `run_ops_scene` | 见 [`运维值班手册.md`](运维值班手册.md) |
| 8 | 分析一下 / 产线概况 / 异常分布 | `analyze_platform_brief` | 展示 `markdown_report`（分组 + 可绑定指标） |
| 9 | 值班简报 / 产线日报 | `run_ops_scene('ops-daily-brief')` | 口径摘要 + 主对象分布 |

## 实体硬边界

- 同义说法映射到**同一个**英文 id；查空或失败如实说，**禁止改查另一实体充数**。
- 短词歧义（如只说「计划」）：先 `list_platform_entities`，或反问；不要默认改查。
- 目录里没有的对象：告知需补充接口文档，不要假装能查。

当前联调若已接入江西中软资料包，工单示例 id 可能是 `work-orders`，这只是**该资料包**的结果，不是产品内置默认。

## 手工冒烟（对话）

1. 查目录里一个真实实体 → 有中文列名 + 条数（或如实 0 条）
2. 带筛选 → 工具参数含 filters，回复复述条件
3. 「按状态各多少」→ `summarize_platform_data`，分组值来自真实字段
4. 「导出 csv」→ 给出绝对路径和行数
5. （可选）`ENABLE_ENTITY_GUARD=true` 时故意混实体应被拦并改查

无 LLM 别名断言：`make smoke-entity-phrases`
