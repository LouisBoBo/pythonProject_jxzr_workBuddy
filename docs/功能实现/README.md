## 怎么读分册（给开发 / 深入）

每篇统一四块：

1. **实现原理** — 解决什么问题、关键设计、和谁容易混、依赖什么配置  
2. **实现流程** — 按步骤写清前端 → API → Agent/旁路 → 落盘/回显；含失败排查表  
3. **技术及用法** — 对应仓库路径与配置项  
4. **扩展建议** — 可做 / 慎做 / 不要做  

略懂技术建议阅读顺序：**00 → 你关心的功能编号**；原理和流程两节是重点。
